# Shall We Slay Bingo

[![Runelite Plugin](https://img.shields.io/badge/Runelite-Plugin-blue.svg)](https://runelite.net/)

## Description

**Shall We Slay Bingo** is a RuneLite plugin created by **Spade 2i**, designed for tracking team objectives, unique drops, and completed tiles during Shall We Slay clan events — or similar group activities.  

It’s perfect for clans looking to gamify Slayer events and keep team progress organized.  

---

## Features

- Track team objectives and unique drops.
- Customizable bingo board (default 5x5 grid, configurable).
- Export and import board JSON for easy sharing.
- Attach screenshots to each tile for proof.
- Send completed tile notifications to a Discord webhook.
- Offline mode support (optional).
- Reset board to default tiles anytime.
