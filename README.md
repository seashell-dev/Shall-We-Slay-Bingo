# Shall We Slay Bingo

[![Runelite Plugin](https://img.shields.io/badge/Runelite-Plugin-blue.svg)](https://runelite.net/)

## Description

**Shall We Slay Bingo** is a RuneLite plugin designed for tracking team objectives, unique drops, and completed tiles during **Shall We Slay** events or similar clan activities.  

Players can complete objectives, attach screenshots for verification, and optionally upload proof to a Discord webhook.  

---

## Features

- Track team objectives and unique drops.
- Customizable 5x5 (or larger) bingo grid.
- Export and import board JSON for easy sharing.
- Attach screenshots to each tile for proof.
- Send completed tile notifications to a Discord webhook.
- Offline mode support (optional).
- Reset board to default tiles anytime.
